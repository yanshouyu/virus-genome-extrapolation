# Interim data: TSS sequence ranges (regenerated on demand)

This folder contains processed data derived from raw sources. Files are **not** tracked in Git if they can be reproduced; committed files serve as fixed interim checkpoints.

## Contents
- `tss_seq_range.csv` — Processed TSS sites with sequence ranges. Generated by [`notebooks/0_process_baculovirus_tss.ipynb`](notebooks/0_process_baculovirus_tss.ipynb). This CSV is committed as a fixed interim data point.
- `tss_seq_range.fasta` — Extracted 300bp sequences around TSS sites in FASTA format. Derived from `tss_seq_range.csv` using the extraction script.
- `tss_neg_seq_range.fasta` — Extracted 300bp negative sequences (non-TSS regions) in FASTA format. Generated by the negative extraction script to balance the positive set.
- cluster output TSVs (representative/member pairs, cluster sizes, and summary report) for grouped train/test splitting (see “Sequence clustering” below).

## Reproduce the FASTA data
From the repo root:
```bash
# Run the positive extraction script (outputs to data/interim/tss_seq_range.fasta)
python3 scripts/extract_tss_sequences.py

# Run the negative extraction script (outputs to data/interim/tss_neg_seq_range.fasta)
python3 scripts/extract_neg_tss_sequences.py
```

The notebook `notebooks/0_process_baculovirus_tss.ipynb` documents the CSV generation but does not need to be rerun, as the CSV is committed.

## Sequence clustering (for grouped train/test splits)
To avoid data leakage when splitting into training/validation/test sets, we cluster the positive and negative sequence sets using MMseqs2 (linclust). This groups similar sequences together so that all members of a cluster can be assigned to the same split.

The clustering is performed with `scripts/mmseqs_cluster_30id.sh`, which uses these key MMseqs2 options:
- `--min-seq-id 0.30` (30% minimum sequence identity)
- `-c 1.0` (100% coverage, full-length / bidirectional)
- `--cov-mode 0` (coverage relative to the shorter sequence)
- `--seq-id-mode 1` (identity relative to the shorter sequence)

Example (from the repo root):
```bash
# Activate conda environment (adjust as needed)
conda activate cpen_14

# Cluster positive (TSS) sequences
scripts/mmseqs_cluster_30id.sh data/interim/tss_seq_range.fasta -p cluster_tss_pos

# Cluster negative (non-TSS) sequences
scripts/mmseqs_cluster_30id.sh data/interim/tss_neg_seq_range.fasta -p cluster_tss_neg
```

This produces the following outputs in `data/interim/`:
- `cluster_tss_pos_clusters.tsv`
- `cluster_tss_pos_cluster_sizes.tsv`
- `cluster_tss_pos_cluster_report.tsv`
- `cluster_tss_neg_clusters.tsv`
- `cluster_tss_neg_cluster_sizes.tsv`
- `cluster_tss_neg_cluster_report.tsv`
