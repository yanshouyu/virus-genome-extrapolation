# Reproduction and artifact locations

Use the existing WSL ece657d environment for analysis/reporting and cpen_14 for the Biopython sampling audit. The Nibi environment is unchanged from October 19; the job launchers record module/environment paths. No dependency upgrades were performed.

## Cluster extraction and analysis

From the Nibi repository root, choose fresh output paths or edit both launchers to a fresh experiment root before rerunning. Existing output directories deliberately cause failure; do not delete prior runs.

```bash
mkdir -p runs/2026-10-20
sbatch scripts/extract_validation_embeddings.slurm
# Replace EXTRACT_ARRAY_ID with the returned array job ID.
sbatch --dependency=afterok:EXTRACT_ARRAY_ID scripts/analyze_validation_readouts.slurm
```

Both source models and pinned custom code must already be cached: extraction runs offline. The GPU array has two tasks with concurrency two, one small H100 MIG slice each. The CPU job uses def-aucoin (resolved by the scheduler to def-aucoin_cpu), four CPUs and 16 GB RAM. Neither script reads test.csv. The mean excludes padding and all tokenizer-declared special IDs from the actual emitted token IDs; the tokenizer's inconsistent returned special_tokens_mask is not used.

Readout fitting, scaling and probability replay all use float64, even though extracted embeddings are float32. Any logistic convergence warning fails the analysis. COMPLETE is written only after all five model families finish both fixed-validation and nested grouped analysis. Exported fixed-validation readouts are trained on training only. Outer fold predictions come from models trained only on the other outer folds; C selection uses three grouped inner folds.

## Collected outputs and local report

Nibi: `/home/shouyu/projects/def-aucoin/shouyu/virus-genome-extrapolation/runs/2026-10-20/embeddings/` and `readouts/`.

Local copies: `runs/2026-10-20/collected/embeddings/` and `readouts/`. Failed mask and mixed-precision attempts remain in separate Nibi directories. Their metrics are not scientific results. Job accounting includes failed and cancelled jobs as well as final successful jobs.

Copy the complete embeddings and readouts directories from Nibi into the local collected/ directory, then:

```bash
cp runs/2026-10-20/collected/readouts/metrics.json documents/experiments-2026-10-20/readout-metrics.json
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python scripts/summarize_validation_readouts.py
PYTHONPATH=src OMP_NUM_THREADS=2 python -m pytest -q
```

The summary independently loads exported coefficients, reconstructs validation probabilities, recomputes metrics, exports compact CSV predictions and draws the figure. It records package versions from experiment metadata, source hashes and cache/model hashes. To rerun the sampling audit in the existing cpen_14 environment:

```bash
PYTHONPATH=src /home/s34yan/miniconda3/envs/cpen_14/bin/python scripts/audit_validation_sampling.py
```

The audit requires the existing ignored GenBank source file and checks only training/validation against it. It writes per-window sampling CSVs and aggregate JSON. No test predictions are generated by any of these new scripts.

The historical nonlinear-head validation loss ranges quoted in the report come from the already completed October 19 report; there is no new nonlinear training or inference here. The external-data plan is a sourced feasibility review; no external cohort has been scored or certified as ready for unseen-genome evaluation.
